## 🕶️ Sobre o Projeto

**E GUI 404** é uma plataforma de conscientização e segurança digital dedicada à documentação, análise e educação sobre:

* crimes cibernéticos;
* golpes online;
* phishing;
* engenharia social;
* fraude digital;
* roubo de contas;
* malware;
* ransomware;
* proteção de identidade;
* segurança financeira;
* privacidade digital.

O projeto transforma ameaças digitais complexas em informações acessíveis, permitindo que usuários reconheçam sinais de risco e adotem medidas preventivas.

> **EXPOSE. EDUCATE. PROTECT.**

O E GUI 404 utiliza uma identidade visual inspirada em cyber intelligence, arquivos investigativos, terminais e estética digital, porém seu propósito é exclusivamente **educacional, defensivo e preventivo**.

---

## 🎯 Objetivo

O principal objetivo do projeto é criar uma central pública de conhecimento sobre segurança digital.

A plataforma pretende ajudar o usuário a responder perguntas como:

* Como reconhecer um golpe?
* Como identificar phishing?
* Como saber se uma mensagem é suspeita?
* Como proteger uma conta?
* O que fazer depois de cair em uma fraude?
* Como identificar engenharia social?
* Como proteger dados pessoais?
* Como reconhecer sites falsos?
* Como identificar falsos investimentos?
* Como reduzir riscos de fraude digital?

# 🎮 Scam Recognition Quiz

Sistema interativo para testar o conhecimento do usuário.

Exemplo:

> Uma pessoa afirma ser funcionária de um banco e solicita um código recebido por SMS.

Possíveis respostas:

```text
[ NORMAL ]

[ SUSPEITO ]
```

Após a resposta:

```text
THREAT DETECTED

Why?

Banks and legitimate services should
not request authentication codes
through unsolicited contact.
```

Objetivo:

**ensinar o usuário a reconhecer padrões de fraude.**
